# Задача №4 "Старая карта"

ФИО: Гопкало Валерия Алексеевна
Номер задачи: 4

## Запуск решения
Программа запускается через терминал:
`python3 solution.py`

## Проектные решения
* Решение реализовано в виде жадного алгоритма, который на каждом шаге максимизирует матож прибыли.
* Для поиска бесплатных безопасных маршрутов используется BFS.
* Если бесплатных путей к новым залам нет, алгоритм Дейкстры оценивает стоимость преодоления завалов. Матож стоимости расчистки неизвестного пути рассчитывается как (1 - p) * day_cost, где p — вероятность целостности.
* Если на пути к самой выгодной цели есть завалы, экспедиция сначала собирает все бесплатные комнаты в текущей ветке поддерева, чтобы не упускать локальную выгоду перед платной командой CLEAR.
